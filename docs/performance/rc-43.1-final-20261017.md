## Reproduce

The complete historical comparator recipe and separate 43.1 stream compatibility
patch remain in the [continuation](../qualification/shen-43.1-continuation.md)
and [patch](../qualification/boehm-43.1-streams.patch). Preserve the original
worktrees and evidence. On Darwin, build the RC code and a separate RC reference:

```sh
git worktree add --detach ../shen-c-qualified 8e01579
git worktree add --detach ../shen-c-reference 8625781
make -C ../shen-c-qualified CC=/usr/bin/cc -j2
make -C ../shen-c-reference CC=/usr/bin/cc -j2
cd ../shen-c-qualified
make CC=/usr/bin/cc test
make CC=/usr/bin/cc sanitize
ASAN_OPTIONS=abort_on_error=1 UBSAN_OPTIONS=halt_on_error=1 make -f Makefile.rc CC=/usr/bin/cc RC_SANITIZE=1 RC_CPPFLAGS=-DSHEN_RC_IMMEDIATE_INTEGERS=0 RC_BUILD=obj/boxed RC_BIN=bin/boxed test
CC=/usr/bin/cc CFLAGS='-O1 -g -DSHEN_RC_VERIFY_OWNERSHIP=1 -fsanitize=address,undefined -fno-sanitize-recover=all -fno-omit-frame-pointer' ASAN_OPTIONS=abort_on_error=1 UBSAN_OPTIONS=halt_on_error=1 scripts/certify-rc.sh
```

Select the new canonical receipt printed by that command for
`scripts/test-rc-toolchain.sh --canonical-receipt RECEIPT`. Run reader controls,
