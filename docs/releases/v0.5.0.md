# Shen-C 0.5.0 release checklist

0.5.0 moves the embedded kernel to community ShenOSKernel 43.2
(Shen-Language/shen-sources tag `shen-43.2`, commit e6947f5), which
Yggdrasil v0.1.0 requires of a stage-1 host. It also carries the community
43.1 kernel move, the compile fallback and the ownership/performance work
listed in the 0.5.0 changelog. This checklist follows `v0.4.0.md`.

1. Merge the kernel-43.2 branch after Linux, macOS, sanitizer and Bifrost
   CI pass. The pinned Bifrost corpus still expects 43.1 in two version
   cases; the workflow allows exactly those until the corpus is updated.
2. Versions are 0.5.0 in `src/rc/main.c`, `src/c/version.h` and
   `flake.nix`.
3. Push a `release/v0.5.0` branch: `.github/workflows/release-binaries.yml`
   runs on `release/**` pushes (not on tags) and uploads the four archives
   (macos-arm64, macos-x86_64, linux-arm64, linux-x86_64) as workflow
   artifacts. Each job runs `scripts/test-release-package.py`, the relocated
   toolchain and the full pinned suite.
4. Tag the merged main commit, build the source archive from that tag, and
   attach the four archives, source archive, receipts and SHA256SUMS to the
   GitHub release by hand, as for 0.4.0.
5. Download the published assets and compare SHA-256 hashes.

Reproduce a package locally from a clean tracked checkout:

```sh
make CC=cc -j2 all test
python3 scripts/package-release.py
python3 scripts/test-release-package.py dist/shen-c-0.5.0-<os>-<arch>.tar.gz \
  --suite-output dist/qualification
```
