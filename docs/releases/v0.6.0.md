# Shen-C 0.6.0 release checklist

0.6.0 moves the embedded kernel to community ShenOSKernel 43.4
(Shen-Language/shen-sources tag `shen-43.4`, commit f34b307). It also carries
the Perceus-derived reference counting for native code listed in the 0.6.0
changelog. This checklist follows `v0.5.0.md`.

1. Merge the kernel-43.4 branch after Linux, macOS, sanitizer and Bifrost
   CI pass. The pinned Bifrost corpus still expects 43.1 in two version
   cases; the workflow allows exactly those until the corpus is updated.
2. Versions are 0.6.0 in `src/rc/main.c`, `src/c/version.h` and
   `flake.nix`.
3. Push a `release/v0.6.0` branch: `.github/workflows/release-binaries.yml`
   runs on `release/**` pushes (not on tags) and uploads the four archives
   (macos-arm64, macos-x86_64, linux-arm64, linux-x86_64) as workflow
   artifacts. Each job runs `scripts/test-release-package.py`, the relocated
   toolchain and the full pinned suite.
4. Tag the merged main commit, build the source archive from that tag, and
   attach the four archives, source archive and SHA256SUMS to the GitHub
   release by hand, as for 0.5.0.
5. Download the published assets and compare SHA-256 hashes.

Reproduce a package locally from a clean tracked checkout:

```sh
make CC=cc -j2 all test
python3 scripts/package-release.py
python3 scripts/test-release-package.py dist/shen-c-0.6.0-<os>-<arch>.tar.gz \
  --suite-output dist/qualification
```
